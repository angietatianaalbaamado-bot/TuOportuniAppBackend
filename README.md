TuOportuniApp Backend 🛠️
Backend REST API para la aplicación móvil TuOportuniApp.
🌐 URL de producción
API: https://tuoportuniappbackend.onrender.com
Documentación Swagger: https://tuoportuniappbackend.onrender.com/api-docs
🛠 Tecnologías

Node.js
Express.js
PostgreSQL (Neon)
JWT + Bcrypt
Swagger UI

⚙️ Instalación local
bashnpm install
Crea .env:
envPORT=3000
JWT_SECRET=tu_secret
DATABASE_URL=tu_url_de_neon
bashnode server/index.js
